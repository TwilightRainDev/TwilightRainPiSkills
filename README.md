# TwilightRainPiSkills

从本地技能库筛出的**自足**技能公开集：只依赖官方技能机制，不含本机环境事实（路径、账号、平台细节），也不依赖任何本地自建工具。

安装：把技能目录放进 `~/.claude/skills/`（或你自己的技能目录）即可，无需其它依赖。

## 技能列表

| 技能 | 说明 |
|------|------|
| [Debugging](Debugging/SKILL.md) | 任何 bug、测试失败、性能回归、构建/集成问题，先分诊找根因，再动手修。 |
| [HtmlDesign](HtmlDesign/SKILL.md) | 制作 Apple 风格的 HTML 制品时使用：官网/营销页（apple.com 视觉）、仿 iOS/macOS 应用界面（HIG）、原型、幻灯片、设计系统、打印与 PDF 交付 |
| [PolishCode](PolishCode/SKILL.md) | 提交前润色代码：复用、简化、效率、抽象层次，并行评审代理并应用修复。 |
| [SecurityAudit](SecurityAudit/SKILL.md) | 安全漏洞审计（OWASP 类）；安装第三方技能前审查 SKILL.md 恶意指令、提示词注入。 |
